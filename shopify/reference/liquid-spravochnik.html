Liquid на една страница

Синтаксис

{{ x }}
output: извежда стойност
{% tag %}
логика, нищо не извежда
x | f: a, k: v
филтър с параметър и именуван параметър
{%- -%}
маха празното място около тага
{% liquid %}
много тагове без скоби; извеждаш с echo
{% # бележка %}
коментар на един ред; {% comment %} за блок
{% raw %}
извежда {{ }} буквално (за JS шаблони)

Истина и лъжа

falsy
само nil и false
truthy
всичко друго, вкл. 0, "", []
!= blank
не е nil, не е празен текст: за текстови настройки и картинки
.size > 0
масивът има елементи
!= empty
обектът съществува (напр. изтрита страница)

Оператори

== != > < >= <=
сравнение
and or
отдясно наляво, без скоби
contains
текст в текст / текст в масив

Тагове

Променливи

Условия

Цикли
