Загрявка от урок 01

Отговори по памет, без да поглеждаш назад. Опитът да си спомниш е това, което затвърждава наученото.

01

Четирите източника на данни

Когато видиш {{ нещо }} в Liquid файл, първият въпрос е откъде идва „нещо“. Отговорът винаги е един от тези четири:

Глобални обекти

Достъпни във всеки Liquid файл.

shopcartcustomersettingsrequestcollections
Обекти на шаблона

Само в своя шаблон и в секциите/блоковете му.

productcollectionarticlepagesearch
Секция и блок

Стойностите от настройките в Theme Editor-а.

section.settingsblock.settingssection.blocks
Твои променливи

Създаваш ги сам с assign, capture или for.

assigncapturefor x in

1. Глобални обекти

Работят навсякъде, освен в Liquid asset файлове.[1] Тези ще ползваш най-често:

shop
Магазинът: shop.name, shop.currency, shop.url
settings
Глобалните настройки на темата от config/settings_schema.json: цветове, шрифтове, лого. Не ги бъркай с section.settings.
cart
Количката: cart.item_count, cart.total_price, cart.items
customer
Влезлият клиент. Ако никой не е влязъл, е nil.[2]
request
Текущата заявка: request.page_type, request.locale.iso_code, request.design_mode (true в редактора)
collections
Всички колекции по handle: collections['lyato'].products
all_products
Продукт по handle: all_products['lenena-riza'].title
pages, linklists
Страници и менюта: pages['za-nas'].content, linklists['main-menu'].links
routes
Правилните URL-и: routes.cart_url, routes.search_url. Не пиши /cart на ръка, защото при друг език пътят се сменя.
Квадратни скоби или точка? Точката е за свойства с фиксирано име (product.title). Квадратните скоби с кавички са за handle-и, особено с тире: collections['lyato-2026'].[3]

2. Обекти на шаблона

Някои обекти съществуват само когато си на съответната страница.[1] Затова секция, която ползва product, работи на продуктова страница, но на началната е празна.

ОбектШаблон, в който съществува
producttemplates/product.json
collectiontemplates/collection.json
articletemplates/article.json
blogblog.json и article.json
pagetemplates/page.json (и page.contact.json)
searchtemplates/search.json

Ако ти трябва продукт или колекция на друга страница, не разчиташ на шаблона. Даваш на търговеца настройка в schema ("type": "product" или "type": "collection") и четеш избора му през section.settings. Точно това ще направиш в задачата.

3. Секция и блок

Ти вече го ползваш. Ето първия ред от твоя sections/simple-hero.liquid:

horizon-first-theme / sections/simple-hero.liquid
{%- liquid
  assign image = section.settings.image_desktop
  assign image_mobile = section.settings.image_mobile | default: section.settings.image_desktop
-%}

section.settings.image_desktop е картинката, която търговецът е избрал в редактора. id-то в schema става името след точката. Вътре в блок същото правиш с block.settings.*. Списъкът с блоковете на секцията е section.blocks.

4. Твои променливи

В същия пример image и image_mobile са твои променливи, създадени с assign. На тях е посветена част 3.

Трик за разследване: не знаеш какво има в обект? Временно сложи <script>console.log({{ product | json }})</script> и отвори конзолата в браузъра.[4] Махни го преди commit.
02

Типове данни и кое е „празно“

Liquid има шест типа: string (текст), number, boolean (true/false), nil (липсваща стойност), array (списък) и empty.[3] Масив не можеш да създадеш директно. Получаваш го от обект (product.tags) или със split.

Най-важното правило в целия урок: само nil и false са „лъжа“. Всичко останало е „истина“, включително 0 и празният текст "".[3]

СтойностКога я срещаш{% if x %}Как да провериш правилно
nilcustomer за гост, неизбрана картинкане влиза{% if x %} е достатъчно
falseизключен checkbox в настройкитене влиза{% if x %} е достатъчно
""текстово поле, оставено празновлиза!{% if x != blank %}
0наличност 0, брой 0влиза!{% if x > 0 %}
[]колекция без продуктивлиза!{% if x.size > 0 %}

Затова в твоя simple-hero правилно пишеш image != blank. blank хваща и nil, и празния текст. Ако не си сигурен, ползвай != blank.

Оператори

Сравнения: == != > < >= <=. Логика: and, or. Плюс contains за текст в текст или текст в масив: {% if product.tags contains 'лято' %}.

Две изненади за човек, който идва от JavaScript:[3]

  • Скоби не се позволяват. {% if (a or b) and c %} е грешка.
  • Изчислява се отдясно наляво. a or b and c означава a or (b and c). При сложно условие го раздели на вложени if.
03

Променливи

assign
Една стойност, по желание с филтри: {% assign title = product.title | upcase %}
capture
Всичко между отварящия и затварящия таг става текст в променлива. За сглобяване на низове с логика вътре.[5]
for … in
Създава променлива за всеки елемент плюс обекта forloop.
increment
Брояч със собствено пространство, отделно от assign. Рядко ти трябва. Брои с assign n = n | plus: 1.

capture

Пример
{%- capture card_label -%}
  {{ product.title }}
  {%- if product.compare_at_price > product.price %} · намаление{% endif -%}
{%- endcapture -%}

<a href="{{ product.url }}" aria-label="{{ card_label | escape }}">…</a>

Тиретата в {%- и -%} махат празните редове около тага.[3] Без тях в променливата влизат и нови редове.

Тагът {% liquid %}

Ти вече го ползваш в simple-hero. Пишеш много тагове един под друг без {% %} на всеки ред.[6] Ако трябва да изведеш нещо вътре в него, ползваш echo вместо {{ }}:

Пример
{%- liquid
  assign on_sale = false
  if product.compare_at_price > product.price
    assign on_sale = true
  endif
  if on_sale
    echo 'Промоция'
  endif
-%}
Защо не assign on_sale = a > b? assign не изчислява сравнения. Резултат true/false получаваш само през if, както е горе.

forloop

Във всеки for имаш forloop.index (от 1), forloop.index0 (от 0), forloop.first, forloop.last и forloop.length.[7] Полезно е за запетаи между елементи или за специален стил на първата карта.

Най-честата грешка: snippet-ът не вижда твоята променлива

Snippet, включен с render, не вижда променливите, създадени извън него.[8] Вижда глобалните обекти и обектите на шаблона, но не и твоите assign. Подаваш ги изрично:

Секция → snippet
{% assign accent = section.settings.badge_color %}

{% render 'sale-badge' %}                                   ← accent е празно вътре
{% render 'sale-badge', product: product, accent: accent %} ← работи

{% render 'product-card' for sale_products as product %}    ← веднъж за всеки елемент
Не кръщавай свои променливи product, collection или cart. Ще закриеш глобалния обект със същото име.[5] Пиши sale_collection, featured_product и т.н.
04

Филтри

Филтърът взима стойността отляво и връща нова. Може да има параметри и се навързва отляво надясно:[9]

Анатомия
{{ product.featured_image | image_url: width: 600 | image_tag: alt: product.title, loading: 'lazy' }}
   └── стойност ─────────┘   └ филтър ┘ └ параметър ┘   └ филтър ┘ └── именувани параметри ──────┘

Shopify има над 150 филтъра в 20 категории. Не ги учиш наизуст. Учиш категориите и знаеш къде да търсиш. Тези ще ползваш почти всеки ден:

КатегорияНай-честитеЗа какво
stringupcase append replace split truncate escape strip_html handleizeтекст
mathplus minus times divided_by round at_least at_mostчисла, проценти
arraysize first join map where sort uniq sumсписъци
moneymoney money_with_currency money_without_trailing_zerosцени
mediaimage_url image_tag video_tag media_tagкартинки, видео
hosted_fileasset_url file_urlфайлове от assets/
htmlstylesheet_tag script_tag link_to placeholder_svg_tagготови HTML тагове
localizationt (translate) format_addressпреводи от locales/
defaultdefaultрезервна стойност
date, formatdate jsonдати, debug

Останалите категории (color, font, metafield, payment, customer, cart, collection, tag) са в справочника.

Пет капана

divided_by
Резултатът е от типа на делителя. {{ 7 | divided_by: 2 }} дава 3, а не 3.5. За десетична дроб дели на 2.0.[10]
money
Форматът (символ, запетая, интервал) идва от настройките за валута на магазина, не от кода.[11] Затова не добавяй „€“ на ръка.
pluralize
Работи само с английски правила.[12] За „1 продукт / 3 продукта“ ползвай {{ 'cart.items' | t: count: cart.item_count }} с ключове one/other в locales/bg.json.
default
Сменя nil, false и празно. Ако false е валиден отговор, добави allow_false: true.[13]
escape
Текст, който търговецът пише в настройките, минава през | escape, преди да влезе в HTML атрибут или заглавие. Една кавичка в заглавието иначе чупи разметката.

Упражнения

Пиши Liquid в тъмното поле. Резултатът се обновява докато пишеш, а рамката става зелена, когато съвпадне с очакваното. Данните са от измислен магазин „Горска сянка“ на продуктова страница.

Първо опитай без подсказка. Ако запецнеш над минута, отвори подсказката. Решението е последна възможност.

  1. snippets/sale-badge.liquid приема product и показва -23%, само ако compare_at_price > price. Документирай параметъра с {% doc %}.[14]
    2. 
          
  2. sections/sale-products.liquid има три настройки: heading (text), collection (collection) и products_to_show (range от 2 до 8).[15] Добави и presets.
    3. 
          
  3. Секцията показва само продукти с намаление и спира при products_to_show.
    4.

Примерно решение (отвори едва след като опиташ)
        

          
snippets/sale-badge.liquid
{% doc %}
  Показва процента отстъпка, ако продуктът е намален.

  @param {product} product - Продуктът, за който се показва баджът.
{% enddoc %}
{%- if product.compare_at_price > product.price -%}
  {%- assign discount = product.compare_at_price | minus: product.price | times: 100 | divided_by: product.compare_at_price -%}
  <span class="sale-badge">-{{ discount }}%</span>
{%- endif -%}

          
sections/sale-products.liquid
{%- assign sale_collection = section.settings.collection -%}

<section class="sale-products">
  <h2>{{ section.settings.heading | escape }}</h2>

  {%- if sale_collection == blank -%}
    <p>Избери колекция от настройките на секцията.</p>
  {%- else -%}
    {%- assign shown = 0 -%}
    <ul class="sale-products__grid">
      {%- for product in sale_collection.products -%}
        {%- if product.compare_at_price > product.price -%}
          <li class="sale-products__card">
            <a href="{{ product.url }}">
              {{ product.featured_image | image_url: width: 600 | image_tag: alt: product.featured_image.alt, loading: 'lazy' }}
              {% render 'sale-badge', product: product %}
              <h3>{{ product.title | escape }}</h3>
              <p>{{ product.price | money }} <s>{{ product.compare_at_price | money }}</s></p>
            </a>
          </li>
          {%- assign shown = shown | plus: 1 -%}
          {%- if shown >= section.settings.products_to_show -%}{%- break -%}{%- endif -%}
        {%- endif -%}
      {%- endfor -%}
    </ul>
    {%- if shown == 0 -%}

    {%- endif -%}
  {%- endif -%}
</section>
