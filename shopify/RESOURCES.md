# Shopify theme development Resources

## Knowledge

- [Liquid reference: basics (shopify.dev)](https://shopify.dev/docs/api/liquid/basics)
  Официално. Типове, truthy/falsy, оператори, whitespace control, handles. Use for: всичко за поведението на езика.
- [Liquid reference: objects / tags / filters (shopify.dev)](https://shopify.dev/docs/api/liquid)
  Официален справочник за всеки обект, таг и филтър, с примери. Use for: проверка на конкретен филтър или свойство.
- [Shopify/theme-liquid-docs (GitHub)](https://github.com/Shopify/theme-liquid-docs)
  Машинно четими JSON данни, от които е генерирана документацията. Use for: пълни списъци на филтри/тагове по категории.
- [Theme architecture (shopify.dev)](https://shopify.dev/docs/storefronts/themes/architecture)
  Официално. Layout, templates, sections, blocks, snippets, settings. Use for: структура на темата и schema.
- [Input settings (shopify.dev)](https://shopify.dev/docs/storefronts/themes/architecture/settings/input-settings)
  Всички типове настройки за schema. Use for: при писане на `{% schema %}`.
- [LiquidDoc (shopify.dev)](https://shopify.dev/docs/storefronts/themes/tools/liquid-doc)
  Тагът `{% doc %}` за документиране на snippets. Use for: snippets с параметри.
- [Shopify CLI theme commands (shopify.dev)](https://shopify.dev/docs/api/shopify-cli/theme)
  Официално. Use for: dev, push, pull, check, share.
- [Shopify/horizon](https://github.com/Shopify/horizon) и [Shopify/dawn](https://github.com/Shopify/dawn) (GitHub)
  Референтни теми на Shopify. Use for: как Shopify решава реални проблеми в Liquid.

## Wisdom (Communities)

- [Shopify Developer Community](https://community.shopify.dev)
  Официален форум за разработчици с модератори от Shopify. Use for: въпроси, преглед на подход, новости.
- [Shopify Community (merchant форум)](https://community.shopify.com)
  Use for: какви проблеми имат реалните търговци. Добър източник на идеи за задачи и портфолио.
