# Тестови данни за dev магазина

`produkti.csv` съдържа 21 продукта (ризи, рокли, чанти, обувки, очила) с варианти, цени в €, стари цени, наличности, тагове и снимки. Снимките идват от DummyJSON, безплатен сайт с тестови данни за прототипи.

## 1. Импорт на продуктите

1. Админ → **Products** → горе вдясно **Import**.
2. Избери `produkti.csv`.
3. **Не** отмятай „Overwrite products with matching handles“.
4. **Upload and preview** → провери първия продукт → **Import products**.
5. Shopify ще прати имейл, когато свърши. Снимките може да се появят няколко минути по-късно.

## 2. Колекции (автоматични, по тагове)

За всяка колекция от таблицата:

1. Админ → **Products** → **Collections** → **Add collection**.
2. **Title** (и по желание **Description**).
3. **Collection type** → **Smart**.
4. „Products must match“ → **all conditions**.
5. Условие: **Tag** → **is equal to** → стойността от таблицата.
6. **Collection image** → **Upload image** → файлът от `collection-images/`.
7. **Save**.

| Title | Tag | Снимка |
|---|---|---|
| Мъже | `мъже` | `maje.webp` |
| Жени | `жени` | `zheni.webp` |
| Аксесоари | `аксесоари` | `aksesoari.webp` |
| Лято | `лято` | `lyato.webp` |
| Промоция | `промоция` | `promotsiya.webp` |

Smart колекцията се попълва сама. Всеки продукт, който по-късно получи тага, влиза автоматично.

**По желание, за „Промоция“:** вместо таг пробвай условието **Compare-at price** → **is not empty**. Тогава колекцията следва старите цени, а не тагове.

## 3. Нарочни „капани“ за упражненията

| Продукт | Какво е особеното |
|---|---|
| Риза на каре синьо-черна | XL е по-скъп (42,90 вместо 39,90) → `product.price_varies` е true |
| Риза на дребно каре | Стара цена само на S и M → `product.compare_at_price` подвежда |
| Рокля на точки | Размер M е изчерпан (наличност 0) |
| Черна дамска чанта | Целият продукт е изчерпан → `product.available` е false |
| Бели спортни маратонки | Промоция + номер 44 изчерпан |
| Чанти и очила | Без опции → `product.has_only_default_variant` е true |
